# 将棋アプリ

ブラウザだけで動く将棋アプリです。インターネット接続・アカウント不要。

- **対コンピュータ（CP）戦** — 10段階の強さ（アマ入門 〜 プロ以上「電脳戦」）＋自作の定跡
- **CP対CPの観戦** — 強さを別々に設定できる。一時停止・1手送り対応
- **対人戦** — 1台の端末を交代で使う
- **2台で対戦** — 同じWi-Fiのスマホ2台で対局（部屋番号を入れるだけ）
- **棋譜の保存と解析** — KIF書き出し／読み込み、評価値グラフ、悪手の指摘、精度%
- **段位測定** — 勝敗に応じて相手の強さが変わり、イロレーティングで棋力を推定
- **アマチュア大会ルール** — 二歩・打ち歩詰めは反則負け、持将棋は24点法

## 起動のしかた（PCで試す場合）

### `start.command` をダブルクリック

ローカルサーバー（`server.js`）が立ち上がり、ブラウザが開きます。
この方法だと、

- 思考エンジンが**別スレッド**で動く（CPが本来の強さで指す／画面が固まらない）
- **スマホ2台での対戦**が使える

終わるときは開いたターミナルのウィンドウを閉じてください。

> 初回は macOS の警告が出ることがあります。その場合は `start.command` を
> **右クリック →「開く」** を選ぶと実行できます。
> Node.js が入っていない場合は簡易サーバーで起動します（2台対戦は使えません）。

### `index.html` を直接開く

ダブルクリックでも遊べますが、ブラウザの制限（`file://` では Worker が使えない）で
**簡易モード**になります。思考が浅くなり、CPが考える一瞬だけ画面が止まります。
画面上部のバッジで今どちらのモードかが分かります。

### 手動でサーバーを立てる場合

```bash
cd "将棋のフォルダ" && python3 -m http.server 8777
```

その後 http://localhost:8777/index.html を開きます。

## 画面の使い方

盤の駒をクリック → 行ける場所に緑の印が出る → 印をクリックで着手。
持駒はクリックして選び、打ちたいマスをクリックします。
成れる場合は「成る／成らず」を聞かれます（必ず成る手は自動）。

| タブ | できること |
| --- | --- |
| 対CP戦 | 手番（先手／後手／ランダム）と強さ、**戦法**を選んで対局 |
| CP対CP | 先手・後手それぞれの強さと指す間隔を決めて観戦 |
| 対人戦 | 1台を交代で使って2人で対局。「手番で自動反転」も選べる |
| 2台で対戦 | 同じWi-Fiの2台で対局（下記） |
| 段位測定 | 3／5／7局続けて対局し、棋力を推定 |
| 棋譜・解析 | 解析の実行、棋譜の保存・KIF書き出し・読み込み |

右下の操作ボタン：**待った**（対CPでは2手戻る）／**ヒント**／**盤を反転**／
**入玉宣言**（27点法）／**投了**／**新規対局**。

キーボード：`←` `→` で1手ずつ、`Home` `End` で最初／最後、`f` で盤反転。

棋譜の行をクリックするとその局面に飛べます。局面を戻してから指すと、
そこから指し直し（分岐）になります。

## スマホ2台で対戦する

1. Mac で `start.command` を起動したままにする（これがサーバーになります）
2. 起動時にターミナルに出る `http://192.168.x.x:8777/` を、**2台のスマホ**で開く
   （Mac とスマホが同じWi-Fiにつながっている必要があります）
3. 片方で「2台で対戦」→ **部屋を作る**（4桁の部屋番号が出ます）
4. もう片方で「2台で対戦」→ 部屋番号を入れて **参加**

あとは自分の手番のときだけ盤を操作できます。盤の向きは各端末で自動的に
自分が下になります。投了・反則負け・持将棋の結果も両方の画面に反映されます。

途中で画面を閉じても、**同じ端末で開き直せば続きから**指せます
（部屋は最後の操作から6時間で消えます）。

> Mac を経由しない完全な直結（P2P）にはしていません。Mac が中継役になるので、
> 対局中は `start.command` のウィンドウを閉じないでください。

## 戦法の指定

「対CP戦」で **先手・後手それぞれの戦法**を選べます（CP対CPにも同じ設定が使われます）。

居飛車／矢倉／角換わり／相掛かり／四間飛車／三間飛車／中飛車／向かい飛車／石田流

- **CPの手番**：指定した戦法の形に組みます
- **あなたの手番**：次に指すべき手を画面に助言します（強制ではありません）
- 序盤24手までが対象。相手に妨げられたり、駒がタダで取られる手になる場合は、
  戦法を離れて通常の読みに戻ります

「おまかせ」を選ぶと、定跡と読みにまかせます。

## 段位測定のしくみ

1. 前回の測定結果（無ければ2級相当）から相手の強さを決めます
2. 勝てば強い相手、負ければ弱い相手に変わります
3. 各局の結果をイロレーティング（K=90〜120）で更新します
4. 指定局数が終わると推定レーティングと段級位を表示・保存します

先手／後手は交互になります。測定中は「待った」「ヒント」は使えません。
記録はこのブラウザ内（localStorage）に保存され、画面右上に表示されます。

## 棋譜解析の読み方

解析すると、各手について次を計算します。

- **評価値グラフ** — 先手視点。上に振れているほど先手有利
- **精度（%）** — 1手ごとの「勝率の下がり幅」から算出した平均。100%に近いほど正確
- **平均損失（点）** — 評価値の損失。歩1枚 ≒ 100点。
  勝敗がほぼ決まった局面は集計から除いています（数値が暴れるため）
- **手の評価** — 勝率の下がり幅で分類
  - `最善` … 最善手と一致、またはほぼ損失なし
  - `疑問手` … 勝率10%以上の損
  - `悪手` … 20%以上の損
  - `大悪手` … 30%以上の損

**推定棋力は1局だけでは大きくぶれます。**静かな展開だと高く、
乱戦だと低く出ます。棋力を正確に知りたいときは「段位測定」を使ってください。

解析の深さは「軽い（0.25秒/局面）」「標準（0.7秒）」「じっくり（1.8秒）」から選べます。
100手の棋譜なら標準で1分強かかります。途中で「中止」できます。

## 実装しているルール（アマチュア大会に準拠）

サイドバーの「ルール」で切り替えられます。

### 指せないもの（誤操作を防ぐため、最初から選べません）

- 駒の動きに反する移動（そもそも行けないマスは選択できません）
- **行き所のない駒** — 1段目の歩・香、1〜2段目の桂（成れる場合は自動で成ります）
- **王手放置・自殺手** — 自玉が取られる手

### 反則負けになるもの（既定：実戦どおり「指せてしまう」）

- **二歩** — 指した瞬間に反則負け。棋譜にもその手が残ります
- **打ち歩詰め** — 同上

駒を選んだときに出る**緑の印は合法手だけ**です。印の無いマスにも駒は置けますが、
それが二歩・打ち歩詰めなら反則負けになります（実戦と同じ扱い）。

「指せない（初心者向け）」に切り替えると、この2つも置けなくなります。

### 持ち時間（既定は「なし」）

「なし」「10分切れ負け」「25分切れ負け」「15分＋秒読み30秒」から選べます。
使い切ると**時間切れ負け**。秒読みつきなら、本時間を使い切った後は
1手ごとに秒読みがリセットされます。
時計は実際の時刻から計算しているので、スマホで他のアプリに切り替えても狂いません。

### 決着のルール

- 詰み・手詰まり・投了
- **千日手**（同一局面4回）＝引き分け
- **連続王手の千日手** ＝ 王手を続けた側の負け
- **持将棋（24点法）** — 双方の玉が敵陣（3段目以内）に入ったら「持将棋判定」ボタン。
  自分の駒（盤上＋持駒、玉は数えない）を **飛角＝5点／その他＝1点** で数え、
  **双方24点以上なら引き分け**、24点未満の側は負け
- **入玉宣言法（27点法）** — 玉が敵陣3段目以内／敵陣の駒10枚以上／王手されていない／
  先手28点・後手27点以上のとき、自分の手番で宣言して勝ち
- **手数上限**（256／320／500手）— 到達時、双方入玉なら24点法、そうでなければ引き分け

棋譜は KIF形式で書き出し・読み込みができ、SFEN／USI（`position ... moves ...`）も
読み込めます。

## ファイル構成

```
index.html            画面
manifest.webmanifest  ホーム画面に追加するための情報
sw.js                 オフライン動作（サービスワーカー）
icons/                アプリのアイコン（tools/make-icons.js で生成）
package.json          クラウドに置くときの設定（start: node server.js）
css/style.css         見た目
js/shogi.js           ルールエンジン（盤面・合法手生成・反則判定・SFEN・棋譜表記）
js/engine.js          思考エンジン（評価関数・αβ探索・定跡・強さレベル・精度指標）
js/book.js            定跡データ（自動生成。tools/build-book.js で作り直せる）
js/worker.js          思考を別スレッドで動かすための入口
js/kifu.js            棋譜の入出力（KIF / SFEN / localStorage）
js/ui.js              盤面描画・入力・ダイアログ
js/app.js             対局進行・CP制御・2台対戦・段位測定・棋譜解析
server.js             静的配信＋2台対戦の中継（Node.js のみ、追加install不要）
start.command         起動用スクリプト（ダブルクリック）
tools/build-book.js   定跡の学習スクリプト
test/                 動作確認用（Node.js で実行）
```

思考エンジンの中身は、駒割＋駒の位置評価＋玉への接近度＋大駒の利きによる評価関数と、
αβ探索（反復深化・置換表・キラー手・静止探索・ヌルムーブ・LMR・王手延長）です。
Apple Silicon の Chrome で毎秒100万〜200万局面ほど読みます。

### 定跡について

`js/book.js` は、**このエンジン自身に序盤を研究させて作ったもの**です。
初期局面から順に局面を展開し、1局面あたり0.75〜2.2秒かけて読ませ、
「最善手との差が20点以内の手」だけを定跡として採用しています
（人がよく指すかどうかではなく、読みの結果で選んでいます）。

弱いレベルは**早めに定跡を離れます**（アマ入門は4手目まで、アマ中級は12手目まで…
アマトップ以上は最後まで）。序盤だけプロ級で中盤から急に弱い、という不自然さを
避けるためです。棋譜解析では定跡を使わず、すべて読み直して評価します。

作り直すときは：

```bash
node tools/build-book.js 1800 42
```

引数は「収録する局面数の上限」と「かける時間（分）」です。時間をかけるほど
深く・正確になります。定跡から外れた局面は通常どおり読んで指します。

## 制限事項

- 定跡は**エンジン自身の読みで作ったもの**で、プロの実戦譜から作ったものでは
  ありません。序盤は「悪くない手」ですが、流行形とは違う形になります。
  相手が定跡から外れた手を指すと、そこから先は通常の読みで指します
- 2台対戦は Mac（`start.command`）が中継役です。Mac を閉じると中断します。
  同じWi-Fi内専用で、外出先からは使えません
- 持ち時間はストップウォッチ方式です。対局中に画面を完全に閉じると、
  その間の時間は進みません（2台対戦では各端末が自分の時計を持ちます）
- 棋譜は分岐を1本しか保持しません（戻って指すと、それ以降は消えます）
- 保存先はブラウザの localStorage です。ブラウザのデータを消すと棋譜も消えます
  （残したい棋譜は KIF で書き出してください）
- 詰将棋の専用モードはありません
